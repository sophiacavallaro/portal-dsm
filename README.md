# Portal DSM — Frontend

Interface React + Vite do Portal DSM.

## 🚀 Tecnologias

- React 18
- Vite
- React Router DOM
- Font Awesome
- Fontsource (Cormorant Garamond + Poppins)

## 📋 Pré-requisitos

- Node.js 18 ou superior
- Backend rodando em `http://localhost:3001`

## ⚙️ Instalação

```bash
git clone https://github.com/seu-usuario/portal-dsm.git
cd portal-dsm
npm install
